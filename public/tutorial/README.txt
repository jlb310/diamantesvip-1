Capturas del tutorial de subida de material
============================================

Deja aquí las capturas de pantalla. La página /admin/tutorial las muestra
automáticamente cuando existen (mientras no estén, muestra un placeholder).

Nombres de archivo esperados:
  - perfil.png      -> pantalla "Editar Perfil"
  - fotos.png       -> pantalla "Fotos y Videos"
  - historias.png   -> pantalla "Historias"

Formato recomendado: PNG, ancho ~1000px. Si usas otro nombre, avísame
para actualizar la página.
